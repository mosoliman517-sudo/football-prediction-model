Every sport works the same way

Home shows today: a game of the day, the daily challenges and live matches.
Games lists every game on one page. Use the chips (Quizzes, Predict, Daily, With a friend) to narrow it down.
The top bar has Search (it finds any game in any sport) and your profile, and every page has a back button.

Where to start

Try the Game of the day on any sport's home page, or the Daily challenges. Stuck? Press Search and type a game's name. Your progress saves in this browser; sign in to keep it on every device.
