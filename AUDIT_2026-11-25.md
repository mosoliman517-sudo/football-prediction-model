# Website audit, 2026-11-25

Recovery point before any change: git tag `pre-audit-2026-11-25`.
Environment: local copy served on this Mac from `docs/`, plus read-only requests to the live site and database. Chromium-based in-app browser; phone width emulated at 375×812. No real phone, Safari or Firefox was used. A Chatterbox recording run was going at the same time, so no timing measurements were taken (they would be misleading).

## A. Overall health

Good. All routes opened without script errors, no sideways scrolling at phone width, the database refuses anonymous reads, and no secret keys are in the code. The defects found were one visible production bug (badges), a few reliability and readability problems, and some outdated text. The main weakness is size and test coverage, not correctness.

Checked and found sound:
- Anonymous read of `profiles`, `progress`, `results` in all three schemas returns no rows; row level security is enabled on every table in the SQL; admin functions all call `is_admin()`.
- Only the publishable key is in the pages. No service-role or other secret keys found in sources or builds.
- A PGN player name containing HTML did not execute in game review. Leaderboard nicknames and avatars are escaped.
- With Lichess blocked, the championship page and explorer show a message instead of spinning.
