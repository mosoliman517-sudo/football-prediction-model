Beat the Model

Out-call a machine-learning model on real matches, test your ball knowledge, and see what the model thinks will happen. Everything is honest: every forecast comes from a model that never saw the match.

Our model

Pick a league to see what the model predicts: title-race odds, a season replay with the model's table beside the real one, how it compares with the bookmakers, and how it all works.

Predictions come from a model that only ever saw earlier seasons (walk-forward), so every match you play was unseen. Bookmaker comparison uses average closing odds with the margin removed.
